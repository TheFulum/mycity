# Мой город

Android-приложение для жителей Могилёва: сообщения о городских проблемах с фотографиями и геометкой, обсуждение и контроль их решения.

![Мой город](photo_2026-05-08_17-16-06.jpg)

## О проекте

Яма на дороге, неработающий фонарь, переполненная урна — о таких проблемах жители часто не знают, куда сообщить. «Мой город» позволяет за минуту оформить обращение: сфотографировать проблему, отметить место на карте и опубликовать. Другие пользователи видят обращение в ленте и на карте, обсуждают его в комментариях, а администратор модерирует обращения и отмечает решённые.

## Возможности

**Обращения**
- Создание обращения с фотографиями, описанием и точкой на карте. Адрес определяется автоматически по координатам.
- Черновики: незаконченное обращение сохраняется и восстанавливается.
- Лента с сортировкой по дате или активности, фильтром по статусу и поиском по названию.
- Галерея фотографий с увеличением, озвучивание текста обращения.
- Подтверждение автором, что проблема действительно решена.

**Карта**
- Все обращения на карте OpenStreetMap, полноэкранный режим.
- Определение текущего местоположения пользователя.

**Общение**
- Комментарии с ответами на конкретные сообщения (древовидные обсуждения).
- Уведомления о новых комментариях и изменении статуса обращений.

**Пользователи**
- Вход по email и паролю или по номеру телефона с SMS-кодом, гостевой режим.
- Профиль с аватаром и историей обращений, просмотр профилей других пользователей.
- Светлая и тёмная тема.

**Администрирование**
- Модерация обращений и закрытие с комментарием.
- Управление пользователями и ролями.
- Статистика по обращениям.

## Технологии

- Java 17, Android SDK (minSdk 27, targetSdk 34), ViewBinding, Material Components
- Firebase Authentication (email, телефон), Cloud Firestore с подписками в реальном времени
- Cloudinary для хранения фотографий
- osmdroid (OpenStreetMap), Google Play Services Location
- Retrofit и Nominatim для определения адреса по координатам
- Glide, Facebook Shimmer, CircleImageView

## Структура

```
app/src/main/java/com/app/mycity/
  ui/          экраны: auth, feed, create, map, profile, admin, main
  data/        модели, репозитории Firestore, клиент Nominatim
  util/        загрузка фото, валидация, сессия, черновики, темы
```

## Запуск

Откройте проект в Android Studio и запустите сборку. Чтобы подключить свой проект Firebase, замените `app/google-services.json`.
