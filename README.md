# Мой город

Android-приложение для жителей Могилёва: сообщения о городских проблемах, новости города, общественный транспорт, интересные места и общение жителей в одном приложении.

![Мой город](photo_2026-05-08_17-16-06.jpg)

## О проекте

«Мой город» объединяет в одном приложении всё, что нужно жителю в повседневной жизни. Можно за минуту сообщить о проблеме (яма на дороге, неработающий фонарь), прочитать свежие новости, посмотреть маршрут автобуса или троллейбуса, поделиться интересным местом и обсудить всё это с другими жителями. Администратор модерирует контент и управляет справочником транспорта.

## Возможности

**Проблемы города**
- Обращение с фотографиями, описанием и точкой на карте, адрес определяется автоматически по координатам.
- Черновики незаконченных обращений.
- Лента с сортировкой, фильтром по статусу и поиском, карта всех обращений.
- Древовидные комментарии, озвучивание текста обращения, подтверждение решения автором.

**Новости**
- Лента новостей Могилёва из RSS-источников с автоматической разбивкой по категориям.
- Фоновое обновление ленты (WorkManager), новости на карте.

**Транспорт**
- Маршруты автобусов, троллейбусов и маршруток с остановками.
- Карта маршрутов и остановок, карточка маршрута.
- Данные о маршрутах собираются собственным парсером сайта городского перевозчика.

**Город**
- Публикации жителей об интересных местах: история, природа, заведения, достопримечательности.
- Лайки, комментарии и модерация публикаций, отображение на карте.

**Общение и профиль**
- Чаты между пользователями.
- Вход по email или по номеру телефона с SMS-кодом, гостевой режим, онбординг для новых пользователей.
- Профиль, уведомления, светлая и тёмная тема.

**Администрирование**
- Модерация обращений и публикаций, управление пользователями, статистика.
- Редактор маршрутов и остановок, импорт справочника транспорта из JSON.

## Технологии

- Java 17, Android SDK (minSdk 27, targetSdk 34), ViewBinding, Material Components
- Firebase Authentication (email, телефон), Cloud Firestore с подписками в реальном времени
- WorkManager для фоновой загрузки новостей, собственный парсер RSS
- Cloudinary для хранения фотографий
- osmdroid (OpenStreetMap), Google Play Services Location, Retrofit и Nominatim
- Node.js-утилиты: парсер маршрутов (axios, cheerio) и загрузчик данных в Firestore (firebase-admin)

## Структура

```
app/src/main/java/com/app/mycity/
  ui/              экраны: проблемы, новости, транспорт, город, чаты, профиль, онбординг, администрирование
  data/            модели и репозитории Firestore, клиент Nominatim
  worker/          фоновая загрузка новостей
  util/            RSS-парсер, категоризация новостей, загрузка фото, валидация, темы
tools/
  transit_scraper/ сбор маршрутов и остановок с сайта перевозчика
  firestore-seed/  загрузка справочника транспорта в Firestore
```

## Запуск

Откройте проект в Android Studio и запустите сборку. Чтобы подключить свой проект Firebase, замените `app/google-services.json`. Для утилит из папки `tools` нужен Node.js и ключ сервисного аккаунта Firebase (`tools/firestore-seed/service-account.json`, в репозиторий не добавляется).
